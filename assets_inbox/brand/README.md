# Jana — brand assets

## Colors
| Role | Hex |
|---|---|
| Crimson (primary) | #BF092F |
| Black (background) | #000000 |
| Light text on dark | #E9E4E5 |
| Ink text on light | #141414 |

## Typefaces (free, Google Fonts)
- **Fraunces** — Black 900, opsz 144, SOFT 100 — the "Jana" name and the J
- **Space Grotesk** — Medium 500, wide tracking — "ALGHASHAM" and small labels

All SVGs have text converted to outlines, so they render the same everywhere without the fonts installed.

## Folders
- `icon/` — the square J mark on its own (crimson tile, black tile, white tile, and on a black canvas)
- `wordmark/` — the name only: `-dark` for dark backgrounds, `-light` for light, `-white` one-color, `name-only` without ALGHASHAM
- `lockup/` — square + name together: stacked (square above, name below) and horizontal (for a navbar)
- `favicon/` — the square J as favicon.ico, SVG, PNGs, Apple/Android icons, manifest and `head-snippet.html`
- `social/` — Open Graph preview, LinkedIn banner, X header, profile pictures

## Usage
- Keep clear space around the square equal to at least the J dot's diameter ×2.
- Don't put the crimson on mid-tone backgrounds; use black, white or the white version.
- Use the icon alone when the space is under ~120px wide.
